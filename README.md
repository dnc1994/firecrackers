# 满地红

年三十，兜里揣满了炮。

傍晚，南方乡下。大人在屋里打牌，爷爷在门口烤火打瞌睡，你手里捏着一根香。

一个第一人称的小沙盒：院子里、村道上、田里看得见的东西，都能拿来玩。没有任务。

## 玩

直接用浏览器打开 `index.html`（需要联网，three.js 和 cannon-es 从 jsDelivr 加载）。

手机：左下摇杆走路，右边滑动转头，底下一排换炮。

| | 电脑 | 手机 |
|---|---|---|
| 走 | WASD | 左下摇杆 |
| 转头 | 点一下画面后移动鼠标（Esc 放开） | 右半边滑动 |
| 点 / 扔（按住蓄力） | 空格 / 左键 | 🔥 |
| 放、插、丢 | Q / 右键 | 👇 |
| 拿、扣 | E | ✋ |
| 换炮 | 滚轮，或炮上标的 1–9、0、-、= | 点底下那排 |

准星下面会一直写着当前这三个键各能干什么。

左上角记着玩出了多少种花样，进度存在浏览器的 localStorage 里，面板里可以清空。

## 部署

纯静态，没有构建步骤：把仓库根目录当站点目录发布即可（Cloudflare Pages 里构建命令留空，输出目录填 `/`）。

## 改

源码按段放在 `src/`，`index.html` 是拼出来的单文件：

```
./build.sh
```

| 文件 | 内容 |
|---|---|
| `00_head.html` | 页面、样式、开场说明 |
| `sec_00` | 渲染、后期、天空、程序贴图 |
| `sec_01`–`sec_03` | 物理、合成的声音、粒子和碎屑 |
| `sec_04` | 提示条、花样（成就）列表 |
| `sec_05` | 村子：地形、房子、树、竹林、电线杆 |
| `sec_06`、`sec_095_things` | 能搬能炸的东西 |
| `sec_07` | 鸡、狗、牛 |
| `sec_08`、`sec_09` | 炮的种类和行为；爆炸以及各种东西的反应 |
| `sec_096_people` | 妈妈、爷爷、表哥、堂妹 |
| `sec_10`、`sec_11` | 玩家的手、输入、界面、主循环 |

单位是 1 = 10 厘米。所有画面和声音都是代码生成的，没有外部素材。
